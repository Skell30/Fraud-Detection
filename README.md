# Tenx Fraud Detection

A project for detecting fraud in e-commerce and banking transactions using machine learning.

## 📂 Structure

- `data/`: Dataset CSVs (or instructions to download them)
- `notebooks/`: Jupyter Notebooks for analysis and modeling
- `src/`: Python modules for preprocessing, training, and utility functions
- `reports/`: Submission reports and visualizations

## 🚀 How to Run

```bash
# Create virtual environment
python -m venv .venv
source venv/Scripts/activate

# Install dependencies
pip install -r requirements.txt
